# Runtime 0.3.0 与职责分离验收

日期：2026-09-10。

## 结论与基线

**#8 已通过验收，源码职责分离已完成。** 指南保留数据、业务规则、薄页面及离线迁移/研究/运营脚本；通用数据库、身份维护、MFA、会话、发布、证据、加密、撤回和恢复均由安装的底座包提供。

实际消费 core 0.2.0 / runtime 0.3.0。上游本地干净 HEAD 与 GitHub main 均为 [`0d0661790b77380fa29497c80e639013745debc3`](https://github.com/BillShiyaoZhang/decentralized-information-community/commit/0d0661790b77380fa29497c80e639013745debc3)。固定包不是相邻源码链接，18 个分发文件与干净源码逐字节一致。包 SHA-256 和 lockfile integrity 见 [产物来源](../vendor/README.md)。没有修改或提交上游代码。

## 账户验收

消费固定包的独立探针覆盖：稳定 actor ID 的密码/TOTP 轮换；丢失 MFA 后的具名离线重新登记；目标多设备及重放结果失效；其他账户不受影响；陈旧版本、错误输入和提交失败完整回滚；角色及普通停用/启用；永久撤销禁止复活。

备份恢复会清除旧密码派生值及 MFA 密文，并要求完整新密码与 TOTP 重新登记。旧 schema 和旧备份不能复活已替换凭据；当前两份撤销/撤回清册必须明确核对，普通停用状态及历史归属保留。

经仓库所有者明确授权，已于 2026-09-10 发布 [#8 验收评论](https://github.com/BillShiyaoZhang/decentralized-information-community/issues/8#issuecomment-5605444135)，并关闭为 completed。此前未发布的权限限制已解除。

## 消费端收尾

| 领域 | 当前实现 |
| --- | --- |
| 内容审核 | 必填 8–400 字理由；平台权限、幂等、发布与加密业务记录同事务提交；记录保留当时隐藏/来源处置结论 |
| 私有处置 | 备注长度/个人信息筛查；合法同状态追加；终态保留决定及链接；校验隐藏目标、公开版本或未发布草稿 |
| 工作台 | `/editor` 筛选分页、详情、备注、版本化处置、内容审核及历史；`/runtime-editor` 保留平台通用入口 |
| 读者风险 | 列表及历史详情展示 reported/confirmed 争议警示，和平台复核逾期警示并存 |
| 账户 | 标准平台 accounts/account 离线命令；不在消费者复制密码、MFA 或恢复逻辑 |
| 研究 | 默认关闭；显式批次及带时区有限窗口；服务器绑定批次；离线纯聚合、授权主机操作和读取审计 |
| 运维 | 平台 backup/restore/retain；消费者对显式备份做真实内存恢复与解密检查，生成有文件指纹的成功/失败证据 |
| 迁移 | 只读关闭的旧 SQLite；显式私有 opt-in/密钥/清册；全新目录恢复；旧五模块只明确补空业务审核模块 |
| 目录维护 | 受审查的业务 JSON/profile 配置与平台内容导入，不继续维护旧 CRUD 应用 |
