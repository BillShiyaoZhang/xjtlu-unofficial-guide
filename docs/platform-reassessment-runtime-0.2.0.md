## 核心验收

- 平台根 `npm test`：120/120 通过。
- 参与者身份是 `mfa:false`、`assurance:invitation`，没有冒充编辑 MFA。
- 资格在服务端核验；邀请单次兑换，会话有绝对和空闲期限。
- 本人摘要不暴露私有正文或内部处置理由；不能读取其他主体、管理列表或发布内容。
- 单设备退出与全主体撤回分离；撤回同时使其他设备及未用邀请失效。
- 恢复不复活旧 session，且必须对齐当前撤回/撤销清册。
- 匿名入口只收有限字段隐私报告；回执不透明，状态读取不泄漏内部载荷。
- 私有导入的公开结果白名单及 link-only 到期规则继续通过消费端回归。

## 已落地

`community/` 保存数据、角色/内容/lifecycle 配置、业务规则和研究说明；`server/` 在平台统一公开投影后补旧 slug、摘要及校园元数据，并验证本项目的材料关系、个人信息、公开目标和研究关联规则。

默认读者页面、受邀参与者流程、问题报告及平台原生编辑入口已经接通。演示与生产数据库和密钥隔离，首次演示初始化之外不自动发布草稿。旧源码和用户原有未提交修改均保留，没有回退。

离线迁移支持只读旧 SQLite，显式私有 opt-in、旧 AAD 认证及受控重加密；恢复只写全新目录，并交给平台验证状态。未知表、缺密钥、未解决主体或未核对清册均显式报错，不以丢数据方式通过。

消费端最终完整回归 **56/56 通过**，包括离线 CLI 禁止通用 HTTP 入口的测试。构建和桌面/移动浏览器检查均针对固定安装包及合成数据；浏览器实测了匿名报告与回执查询，控制台无错误。具体重跑使用根 `npm test`、`npm run build`，操作说明见 [运行与迁移手册](platform-runtime.md)。
