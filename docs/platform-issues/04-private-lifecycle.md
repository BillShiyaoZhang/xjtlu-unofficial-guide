# [Platform] 提供可配置私有工作流、撤回与数据生命周期模块

## 背景与阻塞

`xjtlu-unofficial-guide` 的数据/业务仓库分离需要复用通用私有工作流。评估基线为 main `6a567f4819e430f4e52993d72ebf747e4ea27c20` / core 0.2.0。

目前 [SqliteStore](https://github.com/BillShiyaoZhang/decentralized-information-community/blob/6a567f4819e430f4e52993d72ebf747e4ea27c20/server/store.mjs) 把完整图作为 JSON 快照存储，[HTTP API](https://github.com/BillShiyaoZhang/decentralized-information-community/blob/6a567f4819e430f4e52993d72ebf747e4ea27c20/server/http.mjs) 公开读取该图；没有公开图之外的私有工作流与生命周期服务。

指南已有报告/私有线索队列、指派和处理结果、AES-GCM 载荷、版本化同意、会话撤回、保留清理及维护记录。把这些放入不可变公开图，或者在每个业务 repo 重写这些机制，都不符合迁移目标。

## 请求

提供可选模块或受支持的私有 store 扩展；不要求所有社区使用研究试点，也不将校园统计规则写入 core。

1. 私有记录与公开图分离，以稳定实体/修订 ID 建立关联；包含鉴权访问、敏感详情读取审计、字段保护/加密接口。
2. 配置式状态机支持允许的状态变化、指派、内部备注、决定码和公开结果投影；状态、并发版本、幂等结果和审计原子提交。
3. 可配置资格/同意记录、撤回与会话失效挂钩。撤回应清除需删除的载荷和关联，并拒绝撤回后的在途请求。
4. 通用保留清理与维护任务接口，记录成功/失败及必要运行证据；业务配置字段、TTL、窗口与评估口径。备份/恢复健康信息可接入外部运维提供方。
5. 迁移契约允许保护或受控转换旧记录 ID、加密版本及必要审计，并定义令牌/会话失效策略。指南现有密文 AAD 为 research-intake:v1:<record ID>，不能仅换 ID 后原样复制密文。

## 验收

- [ ] 私有载荷不会进入公开 graph/search/neighborhood/analysis、公开导出、静态产物或普通列表 DTO；授权详情读取有审计。
- [ ] 非法状态跃迁、未授权处理、错误版本及重复请求均有确定行为，状态与审计不会部分成功。
- [ ] 配置的同意撤回立即阻断会话与在途写入，并清理载荷及可关联幂等记录；设备退出与撤回保持可区分。
- [ ] 保留任务可以重复运行；到期密文及其他需删除字段被实际清除，任务失败可观测。
- [ ] 导入 fixture 保留或受控转换加密上下文与外部 ID，公开/私有导出隔离；失败可回滚。
- [ ] 通过一个配置驱动示例说明报告/线索闭环与生命周期，无需在指南继续维护通用队列、加密或调度实现。

使用方保留研究说明、角色/状态枚举、保留时长、试点窗口与统计口径。账号、私有载荷、会话、密钥及受限审计仍是私有运行时数据，不随公开业务仓库分发。
