资料整理日期：2026-09-10。本版共 69 篇，覆盖 20 个主题，参考 53 个公开来源。

本手册面向西交利物浦大学学生，覆盖入学、在校学习、校园生活与发展机会。请先看每篇的校区和人群；“通用入口”表示可从这里查询，不代表所有服务向所有人开放。

这是根据公开网页整理的 AI 初稿，尚未经过人工逐条审核。标为“来源事实”的内容附原站链接；“行动建议”是本手册的整理建议。资料读取日期不等于学校政策发布日期，也不代表已经办理验证。费用、资格、截止日期、课务与健康等事项，请回到对应官方通知核对。

快速使用：刚到校先看“到校准备—账号与系统—住宿与报修”；遇到具体问题查“校园办事—身心健康与求助”；准备学习与申请则看“学习与教务—图书馆—海外交流—实习就业与升学”。

校区：两校区通用入口；人群：学生通用入口。资料整理：2026-09-10；建议复核：2026-10-10。

- **来源事实**：大学出版物页当前列有2026–2027硕士、博士及教育博士手册，而两校区国际生入学指南仍标为2025–2026。 [大学出版物：手册与招生指南](https://www.xjtlu.edu.cn/zh/about/publications)
- **行动建议**：下载时把文件命名为“学生类别—校区—学年—下载日期”，先看目录中的注册、学习要求、支持服务，再定位具体事项。
- **行动建议**：对费用、截止日期、出勤、补考、进阶要求等影响较大的内容，另找当期部门通知；把通知链接和适用入学届一起记录。
- **行动建议**：如果网页目录与附件封面年份不同，把两处截图或标题整理给相应部门确认；不要仅凭文件上传路径中的年份判断有效期。

## 到校准备

<a id="handbook-arrival-master-registration"></a>

### 硕士新生到校前，应核对哪些办理事项？

用手册建立清单，再对照本届录取与迎新通知。

校区：两校区通用入口；人群：研究生、新生。资料整理：2026-09-10；建议复核：2026-12-09。

- **来源事实**：2026/27 硕士手册把注册分为线上、现场和财务三部分，线上环节通过 e-Bridge 核对资料。 [XJTLU Master's Student Handbook AY2026/27](https://www.xjtlu.edu.cn/wp-content/uploads/2026/09/XJTLU_Masters-Student-Handbook_AY2026-27.pdf)
- **来源事实**：同册公布研究生支持邮箱为 pgsupport@xjtlu.edu.cn。 [XJTLU Master's Student Handbook AY2026/27](https://www.xjtlu.edu.cn/wp-content/uploads/2026/09/XJTLU_Masters-Student-Handbook_AY2026-27.pdf)
- **行动建议**：把本人最新录取通知与迎新邮件中的任务逐项列出，分别记录材料、提交入口和完成状态。
- **行动建议**：现场核验前，向招生或研究生支持团队确认身份证明、学历及语言材料是否需要原件或补充文件。
- **行动建议**：核对本人的联系方式和紧急联系人，并把无法按要求到场、材料缺失或系统无法注册的问题提前书面说明。
- **行动建议**：涉及费用或临时困难时，请负责团队说明当前可用渠道，等待正式回复后安排后续步骤。

> 注意：引用的是 2026/27 版手册的事项结构；不同入学批次的具体材料、时间、费用和结果仍须以本人正式通知为准。

<a id="handbook-first-week-action-list"></a>

### 到校第一周，可以按什么顺序把基本事项做完？

按通知、账号、住宿、课程、支持五条线逐项核对，做一张自己的未完成清单。

校区：两校区通用入口；人群：新生。资料整理：2026-09-10；建议复核：2026-10-10。

- **来源事实**：学校在校学生页面集中链接了邮箱、e-Bridge、图书馆、教学日历和学生服务。 [在校学生：学习、学术与服务入口](https://www.xjtlu.edu.cn/zh/current-students)
- **行动建议**：到校前：按本人录取与报到通知列出线上任务、线下核验地点、入住安排和需带证件；不要用别的项目同学的清单代替自己的通知。
- **行动建议**：安顿当天：确认实际分配的住宿地点，检查房间设备并记下物业报修渠道；实走一次宿舍到第一节课教室的路线。
- **行动建议**：开课前：测试学校邮箱、e-Bridge与课程平台的登录，核对课程代码、班级、教室和第一项任务；把未显示的课程或账号报错分别交给教务/课程负责人或IT。
- **行动建议**：第一周内：阅读课程说明、试听图书馆入门培训，找到自己的支持联系人，并把尚未完成的事项写成“问题—负责部门—已提交日期—下一步”。

> 注意：这是整理顺序建议，不是学校正式报到任务清单；具体证件和完成期限以本人当期通知为准。

## 账号与系统

<a id="handbook-arrival-system-bookmarks"></a>

### 常用系统太多，先收藏哪些入口？

从学校在校学生页建立自己的入口清单。

校区：两校区通用入口；人群：新生。资料整理：2026-09-10；建议复核：2026-12-09。

- **来源事实**：学校“在校学生”页集中列出邮箱、Learning Mall、e-Bridge、图书馆和学生一站式等入口。 [在校学生](https://www.xjtlu.edu.cn/zh/current-students)
- **行动建议**：先从该页逐个打开，并按“邮件通知、课程学习、学籍办事、生活服务”保存书签。
- **行动建议**：第一次登录时核对浏览器地址，尽量从学校官网进入，不使用群聊里来历不明的登录链接。
- **行动建议**：给每个书签写一句用途，例如“查注册与证明”或“看课程材料”，减少临时找系统的时间。
- **行动建议**：某个入口打不开时，记录完整页面地址和错误提示，再向对应部门询问。

<a id="handbook-arrival-account-setup"></a>

### 校园账号怎么开始用，忘记密码怎么办？

先确认学校发来的账号信息，再检查找回方式。

校区：两校区通用入口；人群：新生。资料整理：2026-09-10；建议复核：2026-12-09。

- **来源事实**：校园账号可用于学校邮箱、计算机、图书馆和 BOX 等系统。 [IT 服务介绍](https://www.xjtlu.edu.cn/zh/it-services)
- **来源事实**：IT 介绍页指向 UIM（https://sso.xjtlu.edu.cn），用于绑定个人邮箱或手机。 [IT 服务介绍](https://www.xjtlu.edu.cn/zh/it-services)
- **行动建议**：收到学校的账号通知后，按通知中的官方激活指引完成设置，核对学号及姓名是否一致。
- **行动建议**：在首次成功登录后检查找回方式，确保绑定的是自己持续能使用的邮箱或号码。
- **行动建议**：遇到激活或重置失败时，向 IT 提供学号、发生时间及脱敏截图；不要发送密码或验证码。

> 注意：账号激活 FAQ 本次只能检索到摘要，具体按钮和所需证件流程尚未直接核验。

<a id="handbook-arrival-email"></a>

### 校园邮箱在哪里看，手机配置失败怎么办？

优先用网页版确认账号与收信是否正常。

校区：两校区通用入口；人群：学生通用入口。资料整理：2026-09-10；建议复核：2026-12-09。

- **来源事实**：学校邮箱网页版入口是 https://mail.xjtlu.edu.cn。 [IT 服务介绍](https://www.xjtlu.edu.cn/zh/it-services)
- **行动建议**：手机无法添加邮箱时，先测试网页版登录和收发，再判断是账号问题还是客户端设置问题。
- **行动建议**：为入学、课程、办事回执分别建立文件夹，并定期检查垃圾邮件和未读邮件。
- **行动建议**：回复办事邮件时保留原主题和往来记录，在正文写清学号、校区及所问事项。
- **行动建议**：需要手机配置帮助时，从 IT 官网进入最新邮箱指南，或携带设备向本校区 IT 服务窗口求助。

<a id="handbook-arrival-network-login"></a>

### 连上校园 Wi-Fi 却不能上网怎么办？

确认连入学校网络，并检查网页认证。

校区：两校区通用入口；人群：学生通用入口。资料整理：2026-09-10；建议复核：2026-12-09。

- **来源事实**：学校无线网络名称为 XJTLU，网络认证入口为 https://netauth.xjtlu.edu.cn。 [IT 服务介绍](https://www.xjtlu.edu.cn/zh/it-services)
- **来源事实**：官方网络介绍涵盖苏州工业园区和太仓两个校园。 [校园网络](https://www.xjtlu.edu.cn/zh/it-services/%E6%A0%A1%E5%9B%AD%E7%BD%91%E7%BB%9C-intro)
- **行动建议**：确认网络名称后打开浏览器检查是否需要认证；若未自动弹出，可通过已核对的认证地址进入。
- **行动建议**：在公共设备上避免保存登录状态，离开时退出自己的账号。
- **行动建议**：报障时写明校区、楼宇或教室、设备型号、无线或有线连接方式及错误出现的时间。

<a id="handbook-arrival-printing"></a>

### 第一次在校园打印，应该怎么准备？

先提交打印任务，再到自助设备取件。

校区：两校区通用入口；人群：学生通用入口。资料整理：2026-09-10；建议复核：2026-12-09。

- **来源事实**：校园自助打印系统支持打印、复印和扫描，打印任务可在设备上刷校园卡领取。 [IT 服务介绍](https://www.xjtlu.edu.cn/zh/it-services)
- **行动建议**：从 IT 页面进入当前打印指引，先确认提交方式、附近可用设备和计费设置。
- **行动建议**：打印前检查 PDF 页数、纸张尺寸、单双面、彩色或黑白，先用少量页面试打。
- **行动建议**：遇到卡纸或任务重复时，先记下设备位置、任务名称和提示，不要连续反复提交同一文件。
- **行动建议**：离开设备前收齐文件，清除自己的临时材料并退出登录，尤其留意含证件或成绩信息的页面。

<a id="handbook-arrival-box-backup"></a>

### 课程文件和小组资料怎么整理备份？

使用校园 BOX 时同时检查目录和分享权限。

校区：两校区通用入口；人群：学生通用入口。资料整理：2026-09-10；建议复核：2026-12-09。

- **来源事实**：校园云盘 BOX 的入口为 https://box.xjtlu.edu.cn，并提供版本控制功能。 [IT 服务介绍](https://www.xjtlu.edu.cn/zh/it-services)
- **行动建议**：按学期和课程代码建目录，把原始材料、协作稿和最终提交稿分开保存。
- **行动建议**：重要作业在自己的另一处可信存储中保留备份，并检查备份能否打开。
- **行动建议**：分享前确认接收对象与权限，含个人证件或他人信息的材料不要设置为公开链接。
- **行动建议**：小组合作时约定文件命名和最终提交负责人，交稿前核对文件内容，而不只看文件名。

## 校园办事

<a id="handbook-arrival-onestop"></a>

### 不知道该找哪个部门，可以先问谁？

非学术事务可以从学生一站式开始。

校区：两校区通用入口；人群：学生通用入口。资料整理：2026-09-10；建议复核：2026-12-09。

- **来源事实**：学生一站式提供非学术事务咨询，并协助引导至相关部门。 [学习资源与支持](https://www.xjtlu.edu.cn/zh/study/why-study-at-xjtlu/resources-and-support)
- **来源事实**：官方咨询入口包括 onestop@xjtlu.edu.cn 和 https://studentonestop.xjtlu.edu.cn/。 [学习资源与支持](https://www.xjtlu.edu.cn/zh/study/why-study-at-xjtlu/resources-and-support)
- **行动建议**：先用三句话说明“要完成什么、已经做了什么、卡在哪里”，附上校区和学号。
- **行动建议**：如果已有申请编号或邮件往来，一并提供，方便接续处理。

## 语言与学术写作

<a id="handbook-eap-study-habits"></a>

### 全英文学习刚开始，怎样用好 EAP？

围绕本学期任务练习阅读、讨论和表达，逐步形成可重复的学习习惯。

校区：两校区通用入口；人群：新生、本科生。资料整理：2026-09-10；建议复核：2026-12-09。

- **来源事实**：英语语言中心通过 EAP 课程支持英语能力以及学术学习所需技能。 [English Language Centre](https://www.xjtlu.edu.cn/en/study/departments/global-cultures-and-languages-hub/english-language-centre)
- **行动建议**：建议每周挑选一段真实课程阅读，用自己的话写出主张、证据和一个想追问的问题。
- **行动建议**：讨论前建议准备简短提纲并练习解释一个概念；听课时优先记录论点关系和不理解之处。
- **行动建议**：拿到反馈后，建议按结构、论证、引用和语言分类，只选最影响理解的两项做下一轮修改。
- **行动建议**：如学习任务明显超出当前能力，建议带具体作业和反馈向 EAP 老师询问练习方式与可用支持。

> 注意：分班、选课、考核与语言成绩要求以本届正式安排为准。

校区：两校区通用入口；人群：本科生、研究生。资料整理：2026-09-10；建议复核：2026-12-09。

- **行动建议**：会前建议准备题目要求、评分标准、一小段草稿和老师已有反馈，说明想改进论点、结构还是表达。
- **行动建议**：会后建议自己完成修改，并对照原始资料检查引用、数据和结论是否准确。

> 注意：本次未核实具体院系的预约时段；写作辅导不代表代写、润色承诺或分数保证。
