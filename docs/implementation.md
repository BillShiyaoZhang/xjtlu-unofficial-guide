# 阶段 1 软件实现说明

更新日期：2026-08-29

## 1. 交付结论

仓库已增加一个可本地运行的阶段 1 Web 应用，覆盖“编辑签发邀请 → 成年参与者明确同意 → 查找答案 → 查看逐句来源和适用范围 → 反馈/报告/私有线索 → 编辑看指标与复核 → 发布可追溯新版本”的软件闭环。

本次没有部署到 OpenAI Sites，也没有开启公开服务。当前定位是工程预览和本地验收基线，不是已经通过四周试点退出条件的正式产品。

## 3. 关键实现决策

### 3.1 单应用本地适配

设计文档建议最终使用 Next.js + FastAPI + PostgreSQL。本轮先以 Vinext + D1 完成模块化单体，减少本地原型的运行组件。领域不变量位于 SQL 迁移和服务层，不依赖页面状态，因此后续可以迁移到 PostgreSQL 而不改变公开契约。

### 3.2 公开摘要不绕过引用

编辑器保存的检索摘要不再单独作为公开结论。公开列表使用第一条已引用事实句作为摘要；详情页只在逐句来源区域展示结论，避免把无引用的 `summary` 变成规则旁路。

### 3.3 高影响内容默认关闭

当前只有单层编辑白名单，尚未实现领域审核角色、职责分离和来源权威范围。因此 API 和数据库均拒绝高影响答案发布，而不是仅凭“引用类型”误判为安全。

### 3.4 隐藏不改写历史

答案卡隐藏通过 `workflow_operations` 和受控状态触发器完成：旧修订和审计保持不可变，但所有公开读取立即因为卡片状态而失效。恢复公开同样需要理由、`If-Match` 和幂等键。

### 3.5 私有数据最小化

私有线索不接收附件，不自动抓取 URL，不保存邀请凭证或原始研究编号。随机研究编号只以带服务端密钥的 HMAC 查找值存在；邀请与会话只保存令牌摘要。撤回会立即清除研究编号与邀请码映射、幂等缓存和查询/线索关联，终止全部会话并清理私有载荷。到期任务在 30 天清理私有线索、在 120 天删除交互事件并清除剩余外部映射。维护端点默认关闭，必须显式配置独立密钥。

### 3.6 不建立匿名画像的查询计量

搜索正文通过同源 POST 进入服务端，结果页只暴露一小时有效的 AES-GCM 不透明参数；正式参与者参数绑定当前会话。`query_events` 不包含正文、正文哈希、UA、Referer 或匿名 Cookie，只记录长度档、筛选数量、检索状态与结果数；IP 仅在进程内以随机盐不可逆转换后用于短期限流，不写入研究表。一次非空搜索按钮提交定义为一个“明确高意图查询旅程”，筛选细化复用事件并保留最佳曝光排名，因此不需要用可反查的正文哈希去重。正式指标只接受有效、非测试的成年研究会话；任一 `resolved` 才把查询计为解决，未反馈固定进入分母但不进入解决分子。四周闸门只在成对配置的冻结起止时间内计算；参与者分母是窗口内至少产生一次合格查询、且未撤回的去重成年参与者，分享人数必然是其子集。设备退出只终止当前 Cookie 会话，不会删减已经发生的参与者、查询或分享历史，撤回同意才会把相应研究记录排除并清理关联。

### 3.7 邀请、同意与撤回事务边界

邀请由编辑浏览器生成 256-bit 随机代码，服务端只保存摘要；研究编号使用 `PILOT_SECRET` 派生 HMAC。兑换必须同时满足邀请未使用/未撤销/未过期、参与者已线下核验成年，并明确接受集中定义且受测试冻结的 `stage1-v3` 研究说明。该摘要明确区分“清除直接映射”和“仍可能通过精确时间/渠道间接回溯的受限同意审计记录”；后者的精确期限仍是进入真实试点前必须冻结的运营/合规前置。数据库触发器约束单次兑换、会话与同意/邀请/参与者一致、撤销单调性、撤回后的在途事件拒绝，以及测试流量不得成为正式查询。所有带 Cookie 的写请求执行精确 Origin 与 `Sec-Fetch-Site` 校验。

### 3.8 信息新鲜度优先的 PWA

移动端可以安装到主屏幕，但 Service Worker 不缓存答案页面、API、举报、研究线索或编辑内容，仅保存一张静态断网页。断网时产品明确说明需要重新联网获取最新核验答案，也不会离线排队提交写请求。

### 3.9 报告回执与审计闭环

报告成功后用状态 URL 作为持久回执，不依赖易丢失的组件状态。编辑端把“开始复核”和“发布处理结果”拆成两个动作；完成或关闭必须填写公开处理说明。D1 触发器拒绝直接进入终态、同状态改写回复、跳过版本号或缺失工作流操作的更新，并只在合法事务中追加审计记录。

## 4. 验收边界

软件自动化测试能证明数据库不变量、邀请/会话撤销、正式指标分流、同源写保护、URL/PII 基础校验、不可变修订和原子发布/隐藏。它不能替代以下真实世界验收：内容正确率、来源可访问率、任务完成时间、用户覆盖、维护工时、运营响应和合规确认。

因此当前可以进行本地演示和继续开发，但不能仅凭这份实现宣称阶段 1 产品退出条件已满足，也不应直接进入互联网公开上线。

真实试点还必须把单机共享编辑口令替换为具名 MFA 账号、最小权限、服务端可撤销会话和可归因审计，并在反向代理/可观测层丢弃完整 query string（尤其是不透明搜索视图参数）。当前生产 Worker observability 已关闭，仓库提供的本地启动脚本也会禁用 Cloudflare Local Explorer/Observability；实测重启后走完搜索与答案请求，现有追踪计数不再增长。已有本地调试存储、浏览器历史和恢复标签不会被程序擅自删除；曾在早期版本输入敏感内容时，应由试用者手动清除这个本地站点的浏览历史与站点数据。
