# 冷启动测试预览

运行 `npm run preview:cold-start`（等价于 `node scripts/preview-cold-start.mjs`），打开 <http://127.0.0.1:4319/>。停止时在运行终端按 Ctrl+C。

页面顶部黄色说明及每条标题明确标记 **【测试样例】**。新增人物、话题、讨论和回复全部由本地 fixture 生成，不是真实同学投稿，也不是从纸条或小红书复制的内容。已有资料继续使用正式公开快照。

顶部提供每种场景的直达入口：

| 类型 | 可以检查的场景 |
| --- | --- |
| 提问 | 两种合成回答，其中一条讨论已关闭；展开回复和查看完整投稿文本 |
| 活动 | 报名开放、截止、延期、改期、取消、计划结束时间已过 |
| 校园情况 | 仍有影响、确认解决、状态未知 |

共有 10 个合成话题、11 条合成讨论和 11 条合成回复。时间以服务启动时为基准生成：数日后的场景不会因为固定日期过时而全部进入历史。取消、已过计划结束时间、已解决的记录收在首页「往期活动与情况」中，也可以用顶部链接直达。

可以点击「查看回复」，在「回复这条」或「说一句」入口试写文字，再点击「在本页预览文字」。演练组件只显示当前页面输入，不发送、不持久保存。刷新或离开后清空。所有外部链接（包括 GitHub 原文、官方资料来源和模拟报名入口）在这一预览内均停用，并给出页面内说明。

脚本先调用正常 `buildPages()`，随后在专用 HTTP 服务的内存中替换响应。不会把合成内容写入正式内容配置、`community/pages-dist/` 或 runtime。浏览器的 GitHub API 请求被改写到本机只读 `/mock-github/`；服务仅监听 `127.0.0.1`，所有写入方法返回 405，浏览器 CSP 仅允许同源连接。

`npm run build:pages` 和正常 `npm run preview:pages` 使用正式数据，不包含这些合成样例。本预览用于界面和状态覆盖，不代表有真实活跃用户，也不能检验 GitHub 登录与真实发布流程。

验证：`node --test tests/cold-start-preview.test.mjs`。测试覆盖状态计算、完整前端讨论加载器读取本地 API、回复、分页、外链保护、本地输入演练以及正式构建产物隔离。
