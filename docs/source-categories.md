# 来源分类

公开列表、文章详情和每条引用使用三类材料来源：

- **学校官方**：西交利物浦大学官网，以及经确认由学校、部门或学院运营的公众号。
- **用户提供**：用户向本项目直接提供的材料或经历，以及项目维护者撰写的说明。
- **网络资料**：公开网络检索得到的其它资料，包括商业公众号、学生社区、其它高校与政府网站。

这三类表示原始材料来自哪里，与 AI 辅助整理、编辑审核、核验时间彼此独立。用户提交一个学校官网链接时，链接中的原始材料仍属于学校官方；用户自己的经历才属于用户提供。学生 Wiki 中检索到的经验属于网络资料，不能自动当作本项目用户投稿。

研究来源在 `community/handbook/research-*.json` 的每条 `sources` 中填写 `sourceCategory`，可选值为 `university_official`、`user_provided`、`web`。同一个规范 URL 在所有文件中必须一致。`community/source-overrides.json` 按完整 URL 登记研究清单之外的已接收投稿、维护者说明或核对过的公众号，并用 `note` 记录判定依据。

默认只有 `xjtlu.edu.cn` 及其子域名识别为学校官方。`mp.weixin.qq.com` 仅能证明使用微信公众平台；必须先核对账号运营方，再显式标记，不能因为文章提及西浦或发布者名称相似就判为学校官方。其它未登记的公开 URL 默认归网络资料。

SDK 对原站链接来源采用字段白名单；分类注册表与不可变的来源修订分开存放。公开导出和本地阅读接口加入 `citation.sourceCategory`、`citation.publisher` 与去重后的 `answer.sourceCategories`，不会改写原始修订或提升审核状态。修改注册表后重新启动本地服务，并重新导出与发布 Pages 快照。
