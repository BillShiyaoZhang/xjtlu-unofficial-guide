# 初版内容与维护说明

资料整理：2026-09-10。正文见 [西浦非官方手册](handbook.md)，篇目与来源计数见 [覆盖清单](../community/handbook/coverage.json)。

## 这次填充的内容

本次按学生实际任务整理公开网页，覆盖苏州工业园区与太仓校园的新生、在校本科生和研究生。内容包括入学、账号、教务、图书馆、语言写作、住宿交通、社团体育、支持服务、交流、实习升学和科研。每篇包含问题、简要答案、适用范围、来源事实、行动建议、注意事项和复核日期。

原有四张演示卡及其来源、修订和引用保留。新增内容已合入 `community/content.json`，并单独生成 `community/handbook/runtime-import.json` 供已有本地库导入。它们使用 `origin: ai_draft`、`demo: false` 和 `reviewStatus: pending-human-review`。`researchedAt` 记录资料读取日期；`verifiedAt` 留空，不能将模型联网检查冒写成人工审核。

这次扩展的是初版内容候选范围，未改变公开服务的人群、自动发布规则或高影响政策审核规则。GitHub Pages 仍只导出原有四张显式批准的演示卡。阅读完整初版请直接打开正文；新增卡可在授权编辑端检查。此任务未发布网站、操作真实业务库、读取内部邮件或登录学校业务系统。

## 来源方法

- 使用学校官网、教务/IT/图书馆公开页、苏州市公共服务与医院官网核对入口和可定位事实。官方新闻用于说明特定时间的变化，历史手册明确保留学年。
- 学生 Wiki 与开源项目只作为非官方资源导航。已标明归档状态与未验证范围，不使用个人评价、排名或未证实传闻来填补事实空缺。
- 同一 URL 去重，逐句记录来源；原页面未给出发布日期则保留 `null`。页面显示的学年、更新日期或页脚版权年不自动变成发布日期。
- 正文读取成功记为 `opened`；抓取失败、仅有搜索摘要或 JavaScript 空壳记为 `search-result-only`。后者保留在来源索引供继续查证，不用作事实句证据。
- 保存短篇重写与链接，不保存网页全文、内部文件、截图档案或学生个人资料。校区/人群通用入口不意味着所有服务自动适用于所有人。

## 编辑输入与生成

四份 `community/handbook/research-*.json` 是本次初稿的编辑输入。每个 source 记录标题、公开链接、发布方、页面日期、读取日期、读取状态与定位说明；每个 card 的 fact 必须给出本分组的 `sourceKeys`，advice 可不引用。

```powershell
npm run handbook:build
npm run handbook:check
npm test
npm run build
npm run build:pages
```

构建会验证事实引用、来源读取状态、适用范围和平台数据契约，生成完整正文、覆盖清单、独立导入包，并更新主内容与目录。检查模式验证生成结果和编辑输入一致。它不联网，也不会更新核验日期或操作数据库；需要重新查网页时，应先完成实际资料核对。

**这是首次导入快照生成器。** 本批答案与来源固定为 `-v1` 修订；在本批尚未进入运行库之前，可以修改输入并重建。一旦某个运行库已经导入，同 ID 的内容不能重写；后续应使用平台的追加修订工作流，以新的 revision ID、递增 number 和准确 parentRevisionId 关联旧版，并一次提交完整句子与引用。不能用重新生成的 v1 覆盖既有历史，也不能通过删除数据库解决 `IMMUTABLE`。

## 在现有平台中查看

新建本地演示库时，`npm run dev` 会导入完整种子，仅发布四张历史演示答案。重启不再次导入或发布。已有演示库可通过以下显式命令导入本批候选：

```powershell
npm run runtime -- --demo import community/handbook/runtime-import.json
```

该命令需要演示配置已初始化；只追加内容，不改变发布指针。`coverage.json` 列出每张卡的 entity/revision ID，可以在 `/editor` 的修订检查或 `/runtime-editor` 中使用。独立运行环境按 [底座运行手册](platform-runtime.md) 选择自己的 `GUIDE_ROOT` 和导入包；本次未对真实环境执行该命令。

人工编辑核对原站、范围、措辞和复核责任后，通过追加修订记录实际的人工改写/审核结果，再按现有流程提交发布审核。不要仅将 `origin` 改成 `human` 或删除发布限制。高影响结论仍需现有产品规则要求的领域审核；本批只提供入口和准备建议。

| --- | --- | --- |

| 费用、缴款、资助与奖学金 | 仅记录官方核对入口 | 学生类别/专业/学年对应的当期正式通知与负责部门确认 |
| 国际生居留、保险与个案安排 | 提供国际支持入口 | 校方或主管部门当前公开办事说明；个人材料不进入手册仓库 |
| 无障碍与合理调整 | 提供提前表达需求和转介方法；部分图书馆网页抓取失败 | 两校区实际设施与当前申请窗口、材料及隐私说明 |
| 餐饮、快递、门禁、充值、商户、体育和班车 | 有来源的入口已写，动态地点/价格/班次不固化 | 当期官方小程序页面、管理部门公告或可公开核验的实际办理记录 |
| 普通就医、校园值班与心理咨询时段 | 仅提供已核对的联系方式/预约入口 | 两校区当前服务安排，尤其假期与太仓校外就医渠道 |
| 苏州地铁与公共图书馆开放时间 | 交通引用学校访问指引；图书馆页面时段冲突已注明 | 运营方当天线路/开放公告，不能沿用搜索摘要或旧截图 |
| 学生经验 | 收录公开社区入口，不将经验自动升格为事实 | 自愿提供且去除个人信息的校区、入学届、办理时间、原始来源和例外情形 |

维护时优先复核电话、系统入口、校区名称及近期变更。现有卡按 30–90 天设置建议复核日；发现原站冲突或入口失效应立即处理，不等到周期结束。对无法确认的细节，保持明确缺口比写入看似完整的猜测更有用。
