# 常见讨论补充：申研、中介、老师与课程（2026-09-12）

本批已在本地导入 **25 条来源整理**：22 条纸条原帖、3 篇其他公开个人经验。社区话题由39条增加至64条（61条来源整理、3条编辑提问），手册仍为76篇。本文记录本地内容与复用方法；线上更新仍需仓库部署。

按本次整理的主要用途分为6条研究生申请、6条留学中介、6条老师与答疑、7条课程体验与准备；TransferWiki一条同时涉及课程与老师。纸条原帖大多是问题，回答和评论未采集，教师评价维度仍有待同学补充。所有标题、摘要和讨论引导均由编辑整理，不代表原作者在本站发帖。

## 读取方法与范围

- 先试三页最新和一页热门，60条记录得到52条候选，主要是当日生活消息，没有把这些记录凑入本批。
- 从纸条公开H5脚本确认 `/search/message/?q=...&startId=...`。10个关键词分两次有界查询，每词一页，共138条记录；初筛省略2条、跨批去重7条，剩129条发现线索。
- 搜索缺少删除状态，线索保存在本地忽略目录，不能直接发布。选出22条后分两次逐条GET详情，22条均可读且未标记删除；正文与发现时一致。证据记录保存精确链接、发布时间、详情读取时间和正文SHA-256。
- GitHub DIY、Awesome-XJTLU及TransferWiki通过web工具读到正文。记录保留读取范围与申请季背景；没有正文快照或内容哈希，也没有凭申请年份填写精确发布日期。一次为获取哈希而尝试的直接HTTP读取超时，未伪记为读取成功。
- 小红书公开检索未获得可核验笔记正文；本次内置浏览器明确显示“登录后查看搜索结果”。当前批次没有小红书笔记。第三方文章里提到的小红书外链也没有被替代当作已读内容。

本批只保存必要出处与原创概括。未收录代写招揽、资料售卖、机构排行榜、个人敏感经历或具名指控；没有同步账户、头像、联系方式、点赞和评论。读取时间不是人工核验时间。

## 编辑处理

美国12个项目的报价原帖写“5.6左右”，未注明单位，因此不换算金额；新加坡两校报价没有服务清单，不能作市场均价。MTH321的考核变动明确保留“原帖称”的状态，标题也采用疑问句。应数课程帖保留作者对选修数量与纯数课程的主观意见，未延伸为全体学生的需求。

老师相关条目保留原帖用于识别教学对象的姓名或课程代码，内容限于指导、教学、答疑和评分体验；只有提问时明确注明暂无评价。未生成教师评分、机构推荐名次或录取概率。后续分享应注明学年、课程／项目、实际投入与反馈背景。

3篇经验分别为[26Fall西浦CS DIY复盘](https://github.com/Tiezhu-233/Masters-application-diy-guide)、[MPhil文书与中介沟通总结](https://raw.githubusercontent.com/awesome-xjtlu/wiki/main/docs/grad-application/school-of-advanced-technology/computer-science-technology/17-dequnteng-uk.md)、[TransferWiki的Cavaliers学习经历](https://transferwiki.com/bgs/#cavaliers)。其中后者是本科转学分享，仅采用其课程体验；没有作为研究生录取案例。
